# Прогнозирование оттока клиентов в телеком-компании (Telecom Churn Prediction)

## 📌 О проекте
Разработка ML-модели для прогнозирования оттока клиентов на основе исторических данных телеком-компании. Цель — выявить клиентов из группы риска для своевременного принятия мер по удержанию.

## 🎯 Задачи
- Провести разведочный анализ данных (EDA) и предобработку.
- Обучить и сравнить несколько ML-моделей (Logistic Regression, Random Forest, Gradient Boosting, Neural Network).
- Подобрать гиперпараметры для достижения максимального качества.
- Проанализировать важность признаков и сформулировать бизнес-рекомендации.

## 🛠 Стек технологий
- **Язык:** Python 3
- **Библиотеки:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Optuna, Imbalanced-learn (SMOTE)
- **Среда:** Google Colab

## 📊 Результаты
"Лучшая модель Gradient Boosting показала F1-score 0.706 и ROC-AUC 0.885. Ключевыми факторами оттока стали стоимость услуг и количество обращений в поддержку."
